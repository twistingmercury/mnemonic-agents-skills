# Prime

First, if the project has a ./README.md file, read it.

Then if the project is a git repository, run `git ls-files` to understand the project's context. Otherwise, just walk the directory to understand the context.

Ignore files and directories listed in the .gitignore, as well as these:

- `**/_archive/`
- `**/bin/`
- `**/*_/`
- `.claude/`
- `**/.github/`
